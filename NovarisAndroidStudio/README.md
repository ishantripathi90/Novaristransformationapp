# Novaris Transformation Lab Android

Open **this folder** in Android Studio. The main project README and server files are one directory above this folder in the downloaded ZIP.

- Built with Kotlin + Jetpack Compose, Android minSdk 26, compileSdk 35.
- Default backend: https://novaristransformationlab.com/
- The hosted website must contain the matching eight-assessment PHP service and `novaris-app-api.php`.
- No Firebase console, payment gateway, or separate database setup required.
- Build: `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
